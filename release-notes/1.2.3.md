## Version 1.2.3 - WoW 12.1.5 Compatibility

### Compatibility

- **Updated for WoW 12.1.5 (Midnight)** — Bumped the supported interface version to 120105 so the addon loads on the current patch.

### Fixes

- **Items restore again** — 12.1.5 removed the old `PickupItem` and `GetItemIcon` functions, so applying a preset skipped every item slot. BarSnap now uses `C_Item.PickupItem` and `C_Item.GetItemIconByID`.
